# Karate Man Lua

**A browser recreation of the ["カラテ家" (or "Karate Man")](https://rhwiki.net/wiki/Karate_Man_Returns!) minigame from Nintendo's ["リズム天国" (or "Rhythm Tengoku")](https://rhwiki.net/wiki/Rhythm_Tengoku) made with Lua!**

One of my projects made for [Hack Club's](https://hackclub.com/) "[Terra](https://terra.hackclub.com)"

## Controls

Z: Punch

Esc: Pause
