# Karate Man Browser -> [PLAY IT HERE](https://ruzet.itch.io/karate-man-browser) <-

**A browser recreation of the ["カラテ家" (or "Karate Man")](https://rhwiki.net/wiki/Karate_Man_Returns!) minigame from Nintendo's ["リズム天国" (or "Rhythm Tengoku")](https://rhwiki.net/wiki/Rhythm_Tengoku) made with [Godot](https://godotengine.org)!**

One of my projects made for [Hack Club's](https://hackclub.com/) "[Terra](https://terra.hackclub.com)"
A video of the minigame: https://www.youtube.com/watch?v=qQDM8AX8mOY

Z/Click to Punch!
